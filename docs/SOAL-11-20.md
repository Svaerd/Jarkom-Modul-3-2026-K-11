## Soal 11 — DNS Master & Slave

**Soal.** BIND9 di `utahime` (master) & `shoko` (slave) untuk `jujutsu.K11.com`; SOA, NS
delegasi, `allow-transfer`; sinkron otomatis saat serial naik; uji `dig`.

| Script | Node |
|---|---|
| `script/utahime/11-dns-master.sh` | utahime |
| `script/shoko/11-dns-slave.sh` | shoko |
| `script/itadori/11-test-dns.sh` | itadori |

**Poin kunci**: `allow-transfer { 10.69.1.3; };` (hanya slave) + `also-notify`.
Uji: query SOA/NS ke 10.69.1.2 & 10.69.1.3 (serial sama = sinkron), AXFR dari klien **ditolak**.

## Soal 12 — A, CNAME, PTR, Forwarder

**Soal.** A record `jujutsu.K11.com` → gojo; CNAME `www`; zona PTR reverse gojo;
forwarder ke `192.168.122.1`; uji `dig` CNAME/PTR + ping `google.com`.

| Script | Node |
|---|---|
| `script/utahime/12-domain-ptr-forwarder.sh` | utahime |
| `script/shoko/12-domain-ptr.sh` | shoko |
| `script/itadori/12-test-dns.sh` | itadori |

**Poin kunci**: `@ IN A 10.69.1.4`, `www IN CNAME jujutsu.K11.com.`,
zona `1.69.10.in-addr.arpa` → `4 IN PTR jujutsu.K11.com.`, `forwarders { 192.168.122.1; }`.

## Soal 16 — Path-Based Routing `gojo`

**Soal.** `gojo` domain `jujutsu.K11.com`+`www`; `/` → RR maki/panda; `/api` → geto.

| Script | Node |
|---|---|

## Soal 17 — Client IP Terverifikasi

**Soal.** Header `X-Real-IP` + `X-Forwarded-For` di gojo→geto; geto hanya percaya proxy
terpercaya; API simpan `client_ip` terverifikasi ke `request_logs`.

| Script | Node |
|---|---|
| `script/geto/17-trusted-proxy.sh` | geto |
| `script/itadori/17-test-clientip.sh` | itadori |
| `script/kusakabe/16-test-routing.sh` | kusakabe (uji header) |

**Poin kunci**: `set_real_ip_from 10.69.1.4;` + `real_ip_header X-Real-IP;`
→ `$remote_addr` geto = IP klien asli → diteruskan ke worker.
**Bukti**: `request_logs.client_ip` = IP klien, **bukan** 10.69.1.4/10.69.4.2.

## Soal 18 — Backup & Health Check

**Soal.** `kirara` backup server; passive health check `max_fails=2 fail_timeout=5s`;
simulasi mati → request dialihkan ke kirara **tanpa 502**.

| Script | Node |
|---|---|
| `script/geto/18-test-failover.sh` | geto |
| `script/common/18-worker-ctl.sh` | nanami/todo (stop-start) |

**Poin kunci**: `server 10.69.4.7:80 backup;` + `max_fails=2 fail_timeout=5s`.
Prosedur: `stop` nanami & todo → jalankan `18-test-failover.sh failover` → kirara > 0, 502 = 0.

## Soal 19 — Cache & Rate Limit `gojo`

**Soal.** Proxy cache halaman web 10 menit + `X-Cache-Status` (MISS→HIT);
rate limit `/api` 10 req/detik per IP.

| Script | Node |
|---|---|
| `script/gojo/19-cache-ratelimit.sh` | gojo |
| `script/kusakabe/19-test-cache-ratelimit.sh` | kusakabe |

**Poin kunci**:
```
proxy_cache_path /var/cache/nginx/web keys_zone=web_cache:10m;
limit_req_zone $binary_remote_addr zone=api_limit:10m rate=10r/s;
```
`proxy_cache_valid 200 10m;` + `add_header X-Cache-Status $upstream_cache_status;`
`limit_req zone=api_limit burst=5 nodelay; limit_req_status 429;`
